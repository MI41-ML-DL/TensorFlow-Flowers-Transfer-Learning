Класи: `dandelion` (кульбаба), `daisy` (ромашка), `tulips` (тюльпани), `sunflowers` (соняшники), `roses` (троянди). **Не закодовувати числові номери класів вручну:** класові індекси потрібно брати із `info.features["label"].names`, тому що порядок класів не обов'язково алфавітний.

**Джерело класів:** офіційний код `tf_flowers` від TensorFlow Datasets та каталог датасету.

### Що ми намагаємося з'ясувати

1. Який екстрактор краще формує ознаки для цієї вибірки — **MobileNetV2** чи **ResNet50**?
2. Який класичний класифікатор працює найкраще на отриманих ознаках — **Logistic Regression**, **SVM** чи **Random Forest**?
3. Чи змінюється точність, якщо заморозити всю попередньо навчену CNN або дозволити донавчати її останні 20, 50 чи 100 шарів?
4. Які види квітів найчастіше плутаються між собою й чому?

### Гіпотези (перевіряємо, а не стверджуємо наперед)

- **H1:** різні CNN-екстрактори дають різну якість на однаковому датасеті.
- **H2:** нелінійний SVM може працювати інакше, ніж лінійна логістична регресія, навіть на однакових ознаках.
- **H3:** часткове розморожування CNN може покращити точність, але збільшує час навчання та ризик перенавчання.
- **H4:** найбільше помилок виникає між візуально схожими видами квітів (якими саме — покажуть результати).

## 2.2. Розбиття даних

Використовуємо **стратифікований** split: **70% train, 15% validation, 15% test**. Це означає, що пропорції класів у частинах будуть приблизно однаковими.

| Підмножина | Для чого | Що заборонено |
|---|---|---|
| Train | Навчання класифікаторів та CNN-head | Оцінювати на ньому підсумкову здатність узагальнення |
| Validation | Порівняння моделей, вибір freeze depth, рання зупинка | Називати validation-оцінку незалежною фінальною test-оцінкою |
| Test | Одноразова фінальна перевірка після вибору конфігурації | Підбирати гіперпараметри, оглядаючи test-результати |

Фіксуємо `SEED=42` і зберігаємо розбиття в `data/manifest.csv`. У кожного учасника **один і той самий manifest**. Якщо два учасники навчають на різних тестових прикладах, порівняння буде некоректним.

```text
                  tf_flowers (3670 JPEG)

              manifest.csv: train / val / test
                           |
          +----------------+-----------------+
          |                                  |
     MobileNetV2                           ResNet50
    pretrained ImageNet               pretrained ImageNet
       frozen CNN                         frozen CNN
          |                                  |
     feature vectors                    feature vectors
          |                                  |
          +-----------+-----------+----------+
                      |           |
                 Logistic Reg.   SVM      Random Forest
                      \           |           /
                       \---- all 6 pairs ----/
                                 |
                     val metrics and ranking
                                 |
                  final held-out test results
                                 |
                   confusion matrices (6)
                                 |
                     typical error images

Separate controlled branch (on same train/val/test):
MobileNetV2 + new trainable classification head
  -> freeze all / unfreeze 20 / unfreeze 50 / unfreeze 100
  -> graph: number of frozen layers vs VAL accuracy
  -> select on validation -> evaluate selected on test
```

**Важливе методичне розрізнення:**

- У **першій** гілці CNN працює як **фіксований екстрактор ознак**; зверху навчаємо класичні моделі. Це основна частина *benchmark of multiple classifiers on top of several feature extractors*.
- У **другій** гілці додаємо `Dense(5, softmax)` і **частково донавчаємо** CNN, щоб коректно перевірити вплив кількості заморожених шарів. Просто змінювати `trainable=False` без подальшого навчання **не перевіряє** вплив заморожування на точність. Саме тому ми робимо окремий експеримент із fine-tuning. Це доповнення для повного покриття вимоги Transfer Learning, а не зміна теми Assignment 2 на окрему тему Fine-tuning.

# 6. Теорія, яку треба розуміти

## 6.1. Transfer Learning

**Transfer Learning** — перенесення знань, отриманих нейромережею на великому наборі даних (наприклад ImageNet), на нову задачу. Замість повного навчання з нуля беремо готову CNN, яка вже вміє виділяти візуальні ознаки: контури, текстури, складні форми.

У роботі переносимо знання на класифікацію п'яти квіткових класів. Готова CNN перетворює зображення на числовий **feature vector**, а поверх нього навчається класична модель (LM/SVM/RF). Додатково досліджуємо часткове донавчання CNN.

## 6.2. Feature Extractor, Head, Frozen Layer

- **Backbone / feature extractor**: CNN без оригінального класифікаційного шару ImageNet (`include_top=False`).
- **Feature vector**: вихід backbone після `GlobalAveragePooling`; компактне числове представлення зображення.
- **Head**: новий класифікатор. У benchmarking — окремий алгоритм scikit-learn; у freeze-depth — Keras `Dense(5, softmax)`.
- **Frozen layer**: ваги шару не оновлюються під час навчання (`trainable=False`).
- **Unfrozen layer**: ваги можуть оновлюватися, якщо є trainable-параметри та оптимізатор.
- **Batch Normalization**: під час fine-tuning часто залишають у inference mode, щоб не зруйнувати попередньо навчені статистики (детальніше у Keras guide).

## 6.3. Чому саме ці класифікатори

| Модель | Принцип | Плюси | Що перевіряємо |
|---|---|---|---|
| Logistic Regression (LM) | Лінійна межа рішень у просторі ознак | Швидко, простий базовий рівень | Чи достатньо CNN-ознак для лінійного відокремлення |
| SVM (RBF) | Нелінійна межа в просторі ознак | Може знаходити складнішу межу | Чи допомагає нелінійність |
| Random Forest | Ансамбль дерев рішень | Не вимагає масштабування, враховує взаємодії | Як працює деревний підхід на CNN features |

**Масштабування:** для Logistic Regression та SVM — `StandardScaler` **лише fit на train**, потім transform на validation/test. Краще зробити `Pipeline(StandardScaler(), classifier)`, як у коді: тоді test не впливає на mean/std. Для Random Forest scaler не обов'язковий.

## 6.4. Метрики

- **Accuracy**: частка правильних прогнозів серед усіх тестових прикладів: `correct / total`.
- **Precision (для класу)**: серед усіх передбачень цього класу, скільки правильні.
- **Recall (для класу)**: серед справжніх об'єктів цього класу, скільки модель знайшла.
- **F1 (для класу)**: гармонійне середнє precision і recall.
- **Macro-F1**: середнє F1 по класах **з рівною вагою кожного класу** (корисно при дисбалансі).
- **Weighted-F1**: середнє F1 з вагами за чисельністю класів.
- **Confusion matrix**: таблиця, де **рядок** — справжній клас, **стовпець** — передбачений. Діагональ — правильні класифікації.

**Не змішуйте:** у Assignment 2 оцінювання прямо вимагає confusion matrices, accuracy trend, typical errors. ROC/AUC **не зазначені** у вимогах цієї теми (вони були у Classic ML). Можна додати ROC як бонус для себе, але це **не заміна** обов'язкових трьох критеріїв.

## 8.2. Підготовка зображень

CNN отримує зображення форми `(224, 224, 3)`:

1. Прочитати JPEG (`tf.io.read_file`, `tf.io.decode_jpeg`).
2. Перетворити на `float32` та змінити розмір до 224×224 (`tf.image.resize`).
3. Застосувати **потрібну саме для цієї мережі** функцію `preprocess_input`.
4. Пропустити через CNN з `weights="imagenet"` та `include_top=False`.
5. Застосувати Global Average Pooling для отримання вектора ознак.

**Чому не можна переплутати preprocessing:** MobileNetV2 масштабує пікселі приблизно до `[-1, 1]`, а ResNet50 виконує перетворення каналів RGB→BGR та центрування відносно ImageNet. Одна «універсальна нормалізація» для обох CNN може серйозно знизити якість.

**Примітка про resize:** зміна пропорцій фото без збереження aspect ratio іноді спотворює об'єкт. Для базового, узгодженого протоколу ми використовуємо однаковий resize до 224×224. Якщо будете експериментувати з center-crop/letterbox, задокументуйте окремо та не змішуйте результати з первинним порівнянням.

# 11. Accuracy trend: критично важлива вимога 20%

## 11.1. Коректний експеримент

Не можна порівнювати дві випадкові моделі з різним initial seed і назвати це ефектом заморожених шарів. Ми порівнюємо чотири режими **з однакового warm-up стану**. Після warm-up останні блоки CNN мають однакові вихідні ваги для кожного експерименту; змінюється тільки політика заморожування.

### Протокол

1. Побудувати MobileNetV2 з вагами ImageNet без classification top.
2. Додати голову `GlobalAveragePooling2D + Dropout(0.20) + Dense(5, softmax)`.
3. Повністю заморозити backbone, навчити голову 3 епохи на train.
4. Зберегти *теперішні* ваги моделі як спільну стартову точку.
5. Для `unfreeze_last = 0,20,50,100` створити нову модель, відновити однакові ваги з кроку 4.
6. Частково розморозити останні шари (BatchNorm не розморожувати).
7. Запустити до 6 епох із `Adam(1e-5)` та EarlyStopping на validation loss.
8. Записати кількість frozen/trainable layers, **validation** accuracy/loss.
9. Побудувати графік **number of frozen layers vs validation accuracy**.
10. Вибрати кращий режим за validation. Тільки потім одноразово оцінити його на test і побудувати його матрицю помилок.

## 11.2. Чому BatchNorm залишається frozen

BatchNorm зберігає статистики активацій з великого pretraining-датасету. Якщо без контролю оновлювати ці статистики на малому наборі фото, точність може різко змінитися. У коді виклик `backbone(x, training=False)` зберігає inference-поведінку BN навіть під час часткового fine-tuning, а самі BN-шари не беруть участі в оптимізації.

## 11.3. Як пояснити графік

Файл `results/freeze_depth_accuracy_trend.png`:

- **Вісь X:** фактична кількість frozen layers в MobileNetV2.
- **Вісь Y:** validation accuracy після вибраної найкращої за validation-loss епохи в кожному сценарії.
- **Точки:** режими `unfreeze_last=0,20,50,100`.

**Не припускайте**, що чим менше frozen, тим завжди краще. Часткове розморожування може допомогти, але надмірне донавчання може спричинити перенавчання, потребувати більше пам'яті та часу. Якщо крива немонотонна — це нормальний висновок, його треба пояснити реальними значеннями.

## 18.3. `src/01_prepare.py`

```python
"""Download Flowers, make one stratified 70/15/15 split and EDA figures."""
from pathlib import Path
import numpy as np
import pandas as pd
from PIL import Image
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.model_selection import train_test_split
import tensorflow_datasets as tfds

from common import (DATA, IMAGES, MANIFEST, RESULTS, ROOT, SEED,
                    prepare_dirs, set_seeds, load_manifest)


def download_once():
    if MANIFEST.exists():
        print(f"Existing manifest: {MANIFEST}; keeping split unchanged")
        return load_manifest()
    ds, info = tfds.load("tf_flowers", split="train", as_supervised=True,
                         with_info=True, shuffle_files=False)
    names = info.features["label"].names
    rows = []
    for image_id, (image, label) in enumerate(tfds.as_numpy(ds)):
        label = int(label)
        file_path = IMAGES / f"flower_{image_id:05d}.jpg"
        Image.fromarray(image).convert("RGB").save(file_path, quality=95)
        rows.append({"image_id": image_id,
                     "path": str(file_path.relative_to(ROOT)),
                     "label": label, "class_name": names[label],
                     "height": int(image.shape[0]),
                     "width": int(image.shape[1])})
    df = pd.DataFrame(rows)
    # 70% train, 15% validation, 15% test; stratify at both stages.
    train_ids, remainder_ids = train_test_split(
        df.index.to_numpy(), test_size=0.30, stratify=df["label"],
        random_state=SEED)
    val_ids, test_ids = train_test_split(
        remainder_ids, test_size=0.50,
        stratify=df.loc[remainder_ids, "label"], random_state=SEED)
    df["split"] = ""
    df.loc[train_ids, "split"] = "train"
    df.loc[val_ids, "split"] = "val"
    df.loc[test_ids, "split"] = "test"
    assert df["split"].ne("").all()
    assert df["image_id"].is_unique
    df.to_csv(MANIFEST, index=False)
    return df


def figures(df):
    sns.set_theme(style="whitegrid")
    ax = sns.countplot(data=df, x="class_name", order=sorted(df.class_name.unique()))
    ax.set(title="Flower class distribution", xlabel="Class", ylabel="Images")
    plt.xticks(rotation=25, ha="right")
    plt.tight_layout()
    plt.savefig(RESULTS / "eda_class_counts.png", dpi=170)
    plt.close()

    counts = pd.crosstab(df["class_name"], df["split"])
    counts.to_csv(RESULTS / "eda_split_counts.csv")
    counts.plot(kind="bar", figsize=(9, 4), rot=25)
    plt.title("Class distribution across splits")
    plt.xlabel("Class")
    plt.ylabel("Images")
    plt.tight_layout()
```

```python
"""Extract fixed ImageNet features with two CNNs, for exactly the same splits."""
import argparse
import numpy as np
import tensorflow as tf
from common import (BATCH_SIZE, IMG_SIZE, RESULTS, absolute_image_paths,
                    load_manifest, prepare_dirs, set_seeds)


def make_ds(df, preprocess):
    paths = absolute_image_paths(df)
    ds = tf.data.Dataset.from_tensor_slices(paths)
    def load(path):
        image = tf.io.decode_jpeg(tf.io.read_file(path), channels=3)
        image = tf.image.resize(image, IMG_SIZE)  # float32, [0, 255]
        return preprocess(image)
    return ds.map(load, num_parallel_calls=tf.data.AUTOTUNE).batch(BATCH_SIZE).prefetch(tf.data.AUTOTUNE)


def extract(name):
    if name == "mobilenetv2":
        from tensorflow.keras.applications import MobileNetV2
        from tensorflow.keras.applications.mobilenet_v2 import preprocess_input
        backbone = MobileNetV2(weights="imagenet", include_top=False,
                               pooling="avg", input_shape=(*IMG_SIZE, 3))
    elif name == "resnet50":
        from tensorflow.keras.applications import ResNet50
        from tensorflow.keras.applications.resnet50 import preprocess_input
        backbone = ResNet50(weights="imagenet", include_top=False,
                            pooling="avg", input_shape=(*IMG_SIZE, 3))
    else:
        raise ValueError(name)
    backbone.trainable = False
    df = load_manifest().sort_values("image_id")
    result = {}
    for split in ("train", "val", "test"):
        part = df[df["split"] == split]
        X = backbone.predict(make_ds(part, preprocess_input), verbose=1)
        result[f"X_{split}"] = X.astype(np.float32)
        result[f"y_{split}"] = part["label"].to_numpy(dtype=np.int64)
        result[f"id_{split}"] = part["image_id"].to_numpy(dtype=np.int64)
    out = RESULTS / f"features_{name}.npz"
    np.savez_compressed(out, **result)
    print(f"Saved {out}")
    print("Shapes:", {k: v.shape for k, v in result.items()})


if __name__ == "__main__":
    parser = argparse.ArgumentParser()
    parser.add_argument("--model", required=True, choices=["mobilenetv2", "resnet50"])
    args = parser.parse_args()
    prepare_dirs()
    set_seeds()
    extract(args.model)
```

```python
"""Fit 2 extractors x 3 classifiers; select by VAL, report on TEST once."""

import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
from PIL import Image

def classifier(name):
    if name == "logreg":
        return make_pipeline(StandardScaler(), LogisticRegression(max_iter=3000, random_state=SEED))
    if name == "svm":
        return make_pipeline(StandardScaler(), SVC(kernel="rbf", C=1.0, probability=True,
                                                   random_state=SEED))
    if name == "randomforest":
        return RandomForestClassifier(n_estimators=200, min_samples_leaf=2,

def metric_row(y, pred):
    return {"accuracy": accuracy_score(y, pred),
            "macro_f1": f1_score(y, pred, average="macro", zero_division=0),
            "weighted_f1": f1_score(y, pred, average="weighted", zero_division=0)}


def make_confusion(y, pred, classes, title, filename, normalize=None):
    cm = confusion_matrix(y, pred, labels=list(range(len(classes))), normalize=normalize)
    fig, ax = plt.subplots(figsize=(7, 6))
    fmt = ".2f" if normalize else "d"
    sns.heatmap(cm, annot=True, fmt=fmt, cmap="Blues", ax=ax,
                xticklabels=classes, yticklabels=classes)
    ax.set(xlabel="Predicted", ylabel="True", title=title)
    plt.xticks(rotation=35, ha="right")
    plt.yticks(rotation=0)
    plt.tight_layout()
    fig.savefig(RESULTS / filename, dpi=170)
    plt.close(fig)


def plot_errors(df, ids, y_true, y_pred, confidences, classes, model_name):
    wrong = np.where(y_true != y_pred)[0]
    # Highest-confidence mistakes are particularly informative.
    wrong = sorted(wrong, key=lambda i: float(confidences[i]), reverse=True)[:12]
    lookup = df.set_index("image_id")
    fig, axes = plt.subplots(3, 4, figsize=(13, 11))
    for ax, j in zip(axes.ravel(), range(12)):
        if j >= len(wrong):
            ax.axis("off")
            continue
        i = wrong[j]

        with Image.open(ROOT / record["path"]) as im:
            ax.imshow(im)
        ax.set_title(f"True: {classes[int(y_true[i])]}\nPred: {classes[int(y_pred[i])]} ({confidences[i]:.2f})", fontsize=9)
        ax.axis("off")

    fig.tight_layout()
    fig.savefig(RESULTS / "typical_errors.png", dpi=170)
    plt.close(fig)
    records = [{"image_id": int(ids[i]), "true": classes[int(y_true[i])],
                "predicted": classes[int(y_pred[i])],
                "confidence": float(confidences[i])} for i in wrong]
    pd.DataFrame(records, columns=["image_id", "true", "predicted", "confidence"]).to_csv(
        RESULTS / "typical_errors.csv", index=False)
    pairs = pd.DataFrame({"true_label": [classes[int(y_true[i])] for i in np.where(y_true != y_pred)[0]],
                          "predicted_label": [classes[int(y_pred[i])] for i in np.where(y_true != y_pred)[0]]})
```

## 18.6. `src/04_freeze_depth.py`

```python
"""Freeze-depth experiment: val accuracy vs number of frozen MobileNetV2 layers.

Important: never select a freeze configuration on the test set.
This explores fine-tuning as an auxiliary controlled experiment.
"""
import json
import numpy as np
import pandas as pd
import tensorflow as tf
import matplotlib.pyplot as plt
from sklearn.metrics import ConfusionMatrixDisplay, confusion_matrix, classification_report
from common import (IMG_SIZE, BATCH_SIZE, RESULTS, SEED, absolute_image_paths,
                    load_manifest, prepare_dirs, set_seeds)


def make_ds(df, training=False):
    paths = absolute_image_paths(df)
    y = df["label"].to_numpy(dtype=np.int32)
    ds = tf.data.Dataset.from_tensor_slices((paths, y))
    def decode(path, label):
        img = tf.io.decode_jpeg(tf.io.read_file(path), channels=3)
        img = tf.image.resize(img, IMG_SIZE)
        return img, label
    ds = ds.map(decode, num_parallel_calls=tf.data.AUTOTUNE)
    if training:
        ds = ds.shuffle(1024, seed=SEED, reshuffle_each_iteration=True)
    return ds.batch(BATCH_SIZE).prefetch(tf.data.AUTOTUNE)


def build_model(n_classes):
    backbone = tf.keras.applications.MobileNetV2(
        include_top=False, weights="imagenet", input_shape=(*IMG_SIZE, 3))
    backbone.trainable = False
    inputs = tf.keras.Input(shape=(*IMG_SIZE, 3))
    x = tf.keras.applications.mobilenet_v2.preprocess_input(inputs)
    x = backbone(x, training=False)  # BN remains in inference mode, even when partially unfrozen
    x = tf.keras.layers.GlobalAveragePooling2D()(x)
    x = tf.keras.layers.Dropout(0.20)(x)
    outputs = tf.keras.layers.Dense(n_classes, activation="softmax")(x)
    return tf.keras.Model(inputs, outputs), backbone


def configure(backbone, unfreeze_last):
    if unfreeze_last == 0:
        backbone.trainable = False
    else:
        backbone.trainable = True
        start = max(0, len(backbone.layers) - unfreeze_last)
        for i, layer in enumerate(backbone.layers):
            # Keep BatchNorm non-trainable to preserve ImageNet statistics.
            layer.trainable = i >= start and not isinstance(layer, tf.keras.layers.BatchNormalization)
    frozen = sum(not layer.trainable for layer in backbone.layers)
    trainable = sum(layer.trainable for layer in backbone.layers)
    return frozen, trainable


def compile_model(model, lr):
    model.compile(optimizer=tf.keras.optimizers.Adam(learning_rate=lr),
                  loss="sparse_categorical_crossentropy", metrics=["accuracy"])


def main():
    df = load_manifest()
    n_classes = int(df["label"].nunique())
    train_ds = make_ds(df[df.split == "train"], training=True)
    val_ds = make_ds(df[df.split == "val"])
    test_ds = make_ds(df[df.split == "test"])

    # Common warm-up starting point to compare freezing policies fairly.
    set_seeds()
    warm_model, warm_backbone = build_model(n_classes)
    compile_model(warm_model, lr=1e-3)
    warm_model.fit(train_ds, validation_data=val_ds, epochs=3, verbose=2)
    initial_weights = warm_model.get_weights()
    del warm_model, warm_backbone
    tf.keras.backend.clear_session()

    experiments = []
    # Includes full freezing and progressively fewer frozen layers.
    for unfreeze_last in (0, 20, 50, 100):
        set_seeds()
        model, backbone = build_model(n_classes)
        model.set_weights(initial_weights)
        frozen, trainable = configure(backbone, unfreeze_last)
        compile_model(model, lr=1e-5)
        history = model.fit(
            train_ds, validation_data=val_ds, epochs=6, verbose=2,
            callbacks=[tf.keras.callbacks.EarlyStopping(
                monitor="val_loss", patience=2, restore_best_weights=True)])
        val_loss, val_acc = model.evaluate(val_ds, verbose=0)
        experiments.append({"unfreeze_last": unfreeze_last,
                            "frozen_layers": frozen,
                            "trainable_layers": trainable,
                            "val_accuracy": float(val_acc),
                            "val_loss": float(val_loss),
                            "epochs_completed": len(history.history["loss"])})
        model.save_weights(str(RESULTS / f"depth_{unfreeze_last}.weights.h5"))
        del model, backbone
        tf.keras.backend.clear_session()
    frame = pd.DataFrame(experiments)
    frame.to_csv(RESULTS / "freeze_depth_validation.csv", index=False)
    fig, ax = plt.subplots(figsize=(8, 5))
    frame = frame.sort_values("frozen_layers")
    ax.plot(frame["frozen_layers"], frame["val_accuracy"], "o-")
    for _, row in frame.iterrows():
        ax.annotate(f"unfrozen last {int(row.unfreeze_last)}", (row.frozen_layers, row.val_accuracy),
                    xytext=(3, 6), textcoords="offset points", fontsize=8)
    ax.set(xlabel="Number of frozen backbone layers", ylabel="Validation accuracy",
           title="Accuracy trend versus frozen MobileNetV2 depth")
    ax.grid(alpha=0.3)
    fig.tight_layout()
    fig.savefig(RESULTS / "freeze_depth_accuracy_trend.png", dpi=170)
    plt.close(fig)

    # Choose freeze policy only by validation, THEN evaluate one selected version on test.
    winner = max(experiments, key=lambda e: (e["val_accuracy"], -e["val_loss"]))
    set_seeds()
    selected_model, selected_backbone = build_model(n_classes)
    selected_model.set_weights(initial_weights)
    configure(selected_backbone, int(winner["unfreeze_last"]))
    compile_model(selected_model, lr=1e-5)
    selected_model.load_weights(str(RESULTS / f"depth_{winner['unfreeze_last']}.weights.h5"))
    test_loss, test_acc = selected_model.evaluate(test_ds, verbose=0)
    predictions = selected_model.predict(test_ds, verbose=0).argmax(axis=1)
    y_true = df.loc[df["split"] == "test", "label"].to_numpy(dtype=np.int32)
    names = (df[["label", "class_name"]].drop_duplicates()
             .sort_values("label")["class_name"].tolist())
    matrix = confusion_matrix(y_true, predictions, labels=list(range(n_classes)))
    disp = ConfusionMatrixDisplay(matrix, display_labels=names)
    fig, ax = plt.subplots(figsize=(8, 7))
    disp.plot(ax=ax, cmap="Blues", xticks_rotation=35, colorbar=False)
    fig.tight_layout()
    fig.savefig(RESULTS / "freeze_best_confusion.png", dpi=170)
    plt.close(fig)
    with open(RESULTS / "freeze_best_classification_report.txt", "w", encoding="utf-8") as f:
        f.write(classification_report(y_true, predictions, target_names=names, zero_division=0))
    summary = {"best_unfreeze_last": int(winner["unfreeze_last"]),
               "selected_on_val_accuracy": float(winner["val_accuracy"]),
               "test_accuracy_of_selected": float(test_acc),
               "test_loss_of_selected": float(test_loss)}
    with open(RESULTS / "selected_depth_test.json", "w", encoding="utf-8") as f:
        json.dump(summary, f, indent=2)
    print(summary)


if __name__ == "__main__":
    prepare_dirs()
    set_seeds()
    main()
```
